# ShopSphere Data Engineering Platform

## Overview

ShopSphere is a production-style end-to-end data engineering project for an e-commerce company.

The project demonstrates:

- Python
- SQL
- PySpark
- Databricks
- Delta Lake
- Azure Data Lake Storage
- Apache Airflow
- Data Quality
- Dimensional Modeling
- CI/CD
- Power BI

## Architecture

Source Systems → Ingestion → Data Lake → Bronze → Silver → Gold → Data Warehouse → BI
